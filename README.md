# 🏀 NBA Tier List & Roster Manager (2026-2027)

Una aplicación web interactiva e intuitiva para crear, personalizar y gestionar tu propia **Tier List de equipos de la NBA** para la temporada **2026-2027**, con soporte para las Conferencias Este y Oeste, inspección de plantillas (*rosters*) mediante modales flotantes y análisis táctico impulsado por **Google Gemini AI**.

✨ Características Principales
🔄 Drag & Drop Interactivo: Arrastra y suelta fácilmente los logotipos oficiales de los 30 equipos entre los diferentes tiers.

🔀 Filtro por Conferencias: Filtra la vista entre Conferencia Este, Conferencia Oeste o todos los equipos simultáneamente.

🎯 Tiers 100% Personalizables: Crea, renombra, reordena, elimina y cambia el color de cada categoría o nivel según tu criterio.

👁️ Ventana Modal al Doble Clic: Haz doble clic en el logotipo de cualquier equipo para desplegar una ventana flotante con:

Plantilla completa por posiciones (PG, SG, SF, PF, C) y entrenador principal (Head Coach).

Editor interactivo para modificar o añadir jugadores en tiempo real.

Editor de datos raw en formato JSON.

🤖 Integración con Gemini AI:

Análisis Táctico: Genera informes detallados sobre fortalezas, debilidades y proyecciones de victorias para la temporada 2026-2027.

Actualización Inteligente: Consulta noticias e inteligencia reciente para actualizar el roster del equipo automáticamente.

📸 Exportación a Imagen (PNG): Renderiza y descarga tu Tier List final en alta resolución en un solo clic para compartirla en redes sociales.

💾 Persistencia y Respaldos: Guardado automático local (LocalStorage) y exportación/importación de configuraciones en formato .json.

🛠️ Tecnologías Utilizadas
Framework: React 18

Build Tool: Vite

Estilos: Tailwind CSS v4

Iconos: Lucide React

Inteligencia Artificial: API de Google Gemini (gemini-3-flash-preview)

Logotipos: CDN oficial de ESPN NBA
